# axel-avb

## Hi! My name is Alex.

#### I'm a 1C/BSL developer, and this profile is my workshop for AI-assisted 1C tooling. All repos here are original, no forks.

- **MCP servers for 1C/BSL** — read-only code search over procedures & functions (hybrid BM25 + vector in Elasticsearch, dedup + rerank), metadata-config embeddings (Qdrant), syntax helper that parses the platform `.hbk`
- **1C tooling** — unpacker of legacy (non-managed) 1C forms from the configurator's binary export → json-layout / managed-form XML
- **Embedded tinkering** — SPI display overlay (GC9D01) for Orange Pi Zero 2W, VS Code / CMake templates

Real everyday stack: **Python · 1C/BSL · MCP · Elasticsearch · Qdrant · Docker · C/CMake · Linux**
